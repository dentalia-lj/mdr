What these mockups decide

  • One new button in the open Review panel. The picker opens over the page; Done closes it and the panel shows the choice; Approve sends it. Reject is unchanged.
  • The manufacturer is locked. Where the document has none confirmed, the picker first asks for one with the existing manufacturer list.
  • The search starts from the file name. Two ways in besides typing: the items of a published document from the same manufacturer with that word in its file name, and Similar on any row, which lists items with names like it.
  • Fuzzy, but capped: only close matches are listed, at most 200, grouped by catalogue group. "Tick all" works per group.
  • Each row shows the item number, name, whether Business Central marks it as a medical device, the item's current documents by type, and its current document of the same type with its date.
  • Nothing is ticked for you. Every ticked item becomes a confirmed link under the reviewer's name when the document is approved.

Still open

  • What Approve does when a ticked item already has a current document of the same type (Mockup 4, rows B to D) depends on the per-item replacement spec and its four rulings.
  • The Variobase items show "not set" for medical device: Business Central has no device class on these 54 today.
