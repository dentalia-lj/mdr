Solid arrows: the normal chain. Dashed: conditional or human-mediated. Every enqueue goes through app/queue.py; the topology is the enqueue graph, no stage calls another directly. New since 2026-07-24: upload.ingest as a second byte-entry point, the archive as a durable volume served back through the UI, and a parsed-text sidecar. Cross-cutting, so not drawn: every handler's Result envelope lands in job.result and its anomalies in data_anomaly, in the transaction that finishes the job. playbook.reonboard (SCHEDULER, flag off) and the three unproduced Phase-2 tags are omitted here and listed in full below.

Job lifecycle. done and dead free the dedupe key (C2). New since the last map: the handler's Result envelope is persisted to job.result and its anomalies appended to data_anomaly, both in the finishing transaction — a done job and its report can never disagree.

stateDiagram-v2
  direction LR
  [*] --> staged: gate (score below HIGH or flagged)
  [*] --> production: gate (HIGH + ref_gate + no flags)
  [*] --> superseded: gate fast path (older, guard passes)
  staged --> production: approve / bind / high-score redelivery
  staged --> rejected: reject
  production --> superseded: a newer doc supersedes it (C6, at production transition)
  production --> production: never downgraded (CASE guard)

document.status. superseded now has two writers, both audited and idempotent: _apply_supersession (a newer document arrives) and the guarded auto-file fast path (this document is the older one). A superseded document is never resurrected by re-delivery.

stateDiagram-v2
  direction LR
  [*] --> staged: any basis
  [*] --> production: trusted basis + doc production + HIGH
  staged --> production: approve, trusted bases only
  staged --> staged: fetch-context / name-family, forever (C5 CHECK)
  production --> rejected: gate.apply reject cascades every link
  staged --> rejected: gate.apply reject cascades every link

item_document.status. Consumers see a doc for an item only when doc AND link are production. rejected is no longer a writerless enum value: no link may outlive its document's rejection. Note the asymmetry the /items board has to handle — supersession flips only the document's status, so a superseded document can still carry a production-status link.
