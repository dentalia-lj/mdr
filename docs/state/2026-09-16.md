**15.958 rows stamped 2026-08-10**, so INGEST has plainly run, and the `job`

no refresh path**. `SCHEDULER_INGEST_WATCH_DIR` is empty and `BcApiAdapter.read()`
raises without injected records, so neither the scheduled nor the API route can
run today. The CSV route works and is how the snapshot arrived.

The other four blockers were re-tested against "does this stop us shipping?" and
none does: B1 is ruled not-scheduled work, B2's residue needs an external
account rather than code, B4 is one open criterion out of nine, and B5 is
reviewer work with a named reviewer.
