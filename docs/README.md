- **New contributor:** [dev/00-orientation.md](dev/00-orientation.md) -> this page -> [architecture.md](architecture.md) -> [runbook.md](runbook.md), then [code-map.md](code-map.md) when you need to touch code. [dev/limits.md](dev/limits.md) saves you looking for things that are not there.
- **Explaining the system to Dentalia:** [guide/glossary.md](guide/glossary.md) for the vocabulary, then the `guide/pages/` file for the screen in question. Send the Slovene.
- **Agent session:** [CLAUDE.md](../CLAUDE.md) (invariants, conventions) -> [PHASES.md](../PHASES.md) (progress, open scope, gaps) -> [decisions.md](decisions.md) (check before proposing anything that looks already-decided) -> the PRD section for the stage you are building. Reach for [build-log.md](build-log.md) only when you need the reasoning behind a ruling.
